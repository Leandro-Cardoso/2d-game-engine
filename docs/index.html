Visão Geral do Sistema

A 2D Game Engine utiliza uma arquitetura baseada em barramento de eventos para desacoplamento de sistemas.

Nota de Performance: O gerenciamento de memória para as Entidades é feito via Object Pooling para evitar fragmentação no Heap.

Exemplo de Código (C++)

    
        // Inicializando o Logger da Engine
        Log::Init();
        CORE_INFO("Engine Iniciada com sucesso!");
